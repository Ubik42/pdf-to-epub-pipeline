# 可重排教材 EPUB 排版标准

适用于本工程生成的 EPUB 3 教材。首个样本：《运筹学（第5版）》。标准约束的是结构和默认样式；阅读器仍可覆盖字体、字号和行距。

## 导航与标题

- 导航目录按原书印刷目录组织：章为一级，节和章末习题为二级；参考文献等独立后附内容为一级。每个导航链接必须指向存在的 XHTML 文件或标题锚点。
- 印刷目录是目录项的白名单。不能把习题中的 `2.13` 等题号仅凭数字形式当成节标题。正文标题缺失时构建失败，不生成无效书签。
- 章、节、分节使用 `h1`、`h2`、`h3`。标题与后续段落尽量同页，章标题另起页。目录标签保留标题中的数学符号，如 `M/G/1`。

## 正文、例题和图表

- 正文默认两字缩进、适度两端对齐；列表和表格单元格内的段落不缩进。不写死文字颜色，允许阅读器深色模式覆盖。
- `例 2-1` 这样的例题编号加粗，例题开头另起段且不缩进；题干与解答正文保持常规字重。段落中引用“例 2-1”不加粗。
- 图片与紧随其后的独立图号说明合成 `figure` / `figcaption`。图居中，图注置于图下、居中且字号略小；图像的替代文本使用图注。被子图标记隔开的短图题仍居中，但不强行绑定图片。没有可靠图注的图片不凭空补写。
- 表题与紧随其后的表格合成 `table` / `caption`。表题在表上方居中、加粗；单元格保留边框和表头。普通正文中提到“表 2-1”不当作表题。
- 行间公式居中并允许窄屏横向滚动；行内公式随文排列。公式优先保留 MathML，转换失败时保留可见的原始 LaTeX，不静默删除。
- 图、表、例题的样式匹配只处理可确定的相邻结构。扫描识别导致图与图注错位、图中多幅子图或表格跨页时，标为人工校对，不以样式规则猜测其关系。

## 验收

构建后检查导航层级及全部目标锚点、图表资源和引用、EPUBCheck 零 fatal/error/warning。抽查不同章节的图注、表题、例题、公式和窄屏重排。EPUBCheck 通过仅代表文件结构有效，不代表扫描内容无误；阅读器实测必须单独记录。

规范依据：[EPUB 3.3](https://www.w3.org/TR/epub-33/) 的导航文档与 XHTML 内容要求。具体视觉规则为本工程约定。
